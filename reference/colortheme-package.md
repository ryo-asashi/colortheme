# colortheme: A Unified Framework and Interface for Color Palettes and Ramps

The 'colortheme' package provides a unified, environment-based object
framework for managing, retrieving, and customizing color palettes and
color ramps in R. It acts as a flexible dispatcher that supports both
discrete qualitative palettes and continuous sequential/diverging color
ramps. Features a compact URL-like syntax for on-the-fly theme
modifications (such as color reversal, type coercion, and query-based
parameter tuning) and seamless integration with base R graphics and
'ggplot2'.
